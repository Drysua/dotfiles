# Awesome Apps

A curated list of awesome apps and utils.

## 📧 Communication

- [Aerion](https://github.com/hkdb/aerion) — Lightweight, open-source email client with IMAP/SMTP support, unified inbox and keyboard-friendly interface.

## 🎬 Media & Entertainment

- [mpv](https://mpv.io/) — Powerful, lightweight and highly configurable cross-platform media player.
- [Lampa](https://github.com/yumata/lampa) — Free media center for discovering movies and TV shows, with support for multiple platforms.
- [MovieBox-TUI](https://github.com/mesamirh/MovieBox-Tui) — Terminal-based interface for searching, streaming and downloading movies, TV shows and anime using external media players.

## 💻 Development

- [Zed](https://zed.dev/) — High-performance, modern code editor built for speed, collaboration and productivity.
- [Bruno](https://www.usebruno.com/) — Open-source, Git-friendly API client for designing, testing and debugging APIs. Stores collections locally as files.
- [Dataflare](https://dataflare.app/) — Modern database management tool with SQL editor, data browser and support for multiple database systems.

## 🖥️ Desktop & Productivity

- [Flow Launcher](https://www.flowlauncher.com/) — Fast application and file launcher for Windows with customizable shortcuts and community plugins.
- [GlazeWM](https://github.com/glzr-io/glazewm) — Tiling window manager for Windows inspired by i3, featuring keyboard-driven window management and customizable layouts.
- [Pinote](https://github.com/ImFeH2/pinote) — Lightweight floating Markdown notes app. Keep TODOs, code snippets and temporary notes always within reach.

## 🔗 File Sharing

- [LocalSend](https://localsend.org/) — Cross-platform file sharing over a local network. No internet connection, accounts or external servers required.

## 🛠️ Utilities & Text Tools

- [ZITEXT](https://www.zitext.com/) — Lightweight cross-platform text editor with syntax highlighting, Markdown preview, JSON/YAML tools and large-file support.
